Overview:

The AI-Based Symptom Diagnosis System is a machine learning application designed to predict likely diseases based on patient symptoms.

The objective was to improve diagnostic assistance by leveraging machine learning while maintaining transparency and interpretability.

Problem Statement:

Patients often describe symptoms differently.

Examples:

* "Stomach Pain"
* "Abdominal Pain"

Both may refer to similar medical conditions but appear differently in raw datasets.

Additionally, healthcare professionals need explanations behind predictions rather than black-box outputs.

The project aimed to solve both challenges.

Approach:

Step 1:
Collect and clean patient symptom data.

Step 2:
Normalize symptom descriptions.

Step 3:
Train machine learning models.

Step 4:
Generate explainable predictions.

Step 5:
Display disease predictions and contributing symptoms.

Data Processing:

Implemented:

* Missing value handling
* Feature engineering
* Data normalization
* Symptom cleaning

Symptom Normalization:

To improve real-world usability:

Implemented:

* Fuzzy Matching
* Synonym Mapping

Examples:

"Feverish"
→ Fever

"Head Ache"
→ Headache

"Abdominal Pain"
→ Stomach Pain

This improved prediction robustness.

Models Evaluated:

1. Logistic Regression
2. Random Forest

Final Model:

Random Forest

Reason for Selection:

* Higher accuracy
* Better handling of complex feature interactions
* Easier integration with Explainable AI techniques

Performance:

Final Accuracy:
92.28%

Improvement:
11 percentage points higher than Logistic Regression baseline.

Explainable AI:

Implemented using SHAP.

Problem:

Doctors need to understand why a prediction was made.

Solution:

SHAP generates feature contribution scores.

Example:

Prediction:
Diabetes

Contributing Symptoms:

* Frequent Urination
* Increased Thirst
* Fatigue

Each symptom receives a contribution score.

Benefits:

* Improved trust
* Better interpretability
* More transparent predictions

Overview:

This project involved building a complete e-commerce backend capable of supporting products, users, carts, wishlists, orders, and payments.

The goal was to design a production-style REST API system with proper authentication, database management, and payment integration.

Scale:

Database designed to manage more than 50,000 records across multiple entities.

Entities:

* Users
* Products
* Categories
* Carts
* Orders
* Wishlists
* Payments

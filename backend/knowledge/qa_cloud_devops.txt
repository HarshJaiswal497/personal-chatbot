---

Q: What is EC2?

A: Amazon EC2 provides virtual servers in the cloud that allow users to deploy and run applications.

---

Q: Where did you use EC2?

---

Q: What is AWS Lambda?

A: AWS Lambda is a serverless compute service that executes code without requiring server management.

---

Q: Where did you use Lambda?

A: In the serverless architecture version of the Employee Directory project.

---

Q: What is serverless computing?

A: Serverless computing allows developers to run applications without managing servers. The cloud provider handles infrastructure, scaling, and maintenance.

---

Q: What are the benefits of serverless architecture?

A: Lower operational overhead, automatic scaling, reduced infrastructure management, and potential cost savings.

---

Q: What is API Gateway?

A: API Gateway acts as an entry point for APIs and routes requests to backend services.

---

Q: How did you use API Gateway in AWS?

A: In the Employee Directory serverless architecture, API Gateway routed requests to Lambda functions.

---

Q: What is DynamoDB?

A: DynamoDB is AWS's fully managed NoSQL database service.

---

Q: Why use DynamoDB?

A: It provides high scalability, low latency, and serverless operation.

---

Q: What is Amazon S3?

A: Amazon S3 is an object storage service used to store files, media, and static assets.

---

Q: Where did you use S3?

A: For static assets in the Employee Directory serverless deployment.

---

Q: What is Elastic Load Balancer?

A: ELB distributes incoming traffic across multiple application instances to improve availability and fault tolerance.

---

Q: What is Auto Scaling?

A: Auto Scaling automatically adjusts the number of instances based on demand.

---

Q: Why is Auto Scaling important?

A: It improves availability while controlling infrastructure costs.

---
